# Source Audit

The cloned repo started as a broad API mega-list with generated folders for agents, AI, automation, ecommerce, jobs, lead generation, real estate, SEO, social media, travel, videos, and more.

## Removed Or Consolidated

- Broad generated category folders that were not focused on lead generation.
- The giant original README that positioned the repo as a general API directory.
- Repetitive scraper variants and unrelated tools such as entertainment, travel, generic AI, developer tooling, and non-prospecting content.
- Settings/generation scripts from the original mega-list build process.

## Kept And Rewritten

- Strong lead-generation-related Apify links from the source material.
- Existing affiliate tracking where present, especially `?fpr=p2hrc6`.
- Useful source descriptions for what each API provides.
- Pricing notes only when they appeared clearly in the source titles or descriptions.

## Curation Outcome

The repo now favors a smaller set of APIs that support lead discovery, enrichment, validation, buying-signal monitoring, and outbound workflow support.
