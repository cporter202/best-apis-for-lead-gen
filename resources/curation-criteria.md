# Curation Criteria

This repo favors APIs that help builders create practical, monetizable lead generation systems.

## Keep

- Lead discovery sources such as maps, directories, marketplaces, jobs, startup databases, and property sources
- Contact enrichment APIs that add emails, phones, social links, domains, or decision-maker clues
- Validation tools that improve list quality before outreach
- Intent and trigger sources such as hiring, funding, reviews, social discussions, and active project posts
- APIs that combine cleanly into workflows and products

## Remove

- Generic AI tools that do not directly support prospecting
- Consumer entertainment, travel, weather, finance, or unrelated data APIs
- Duplicative scraper variants unless one is clearly stronger for lead gen
- Low-signal tools with vague descriptions or no obvious buyer workflow
- Anything that makes the repo feel like a broad API dump again

## Evaluation Questions

- Who would use this API to make or save money?
- What lead generation job does it perform?
- Does it produce useful inputs for another step?
- Is the data actionable, or merely interesting?
- Can it support a product, service, or repeatable workflow?
