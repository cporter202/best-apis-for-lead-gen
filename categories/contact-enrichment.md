# Contact Enrichment

APIs that add emails, phones, social links, or person/company enrichment fields to existing records.

| API | Best Use |
| --- | --- |
| [AI Contact Details Scraper](../apis/ai-contact-details-scraper.md) | Domain-to-contact enrichment |
| [Clearbit Combined](../apis/clearbit-combined.md) | Structured person/company enrichment |
| [Hunter.io](../apis/hunter-io.md) | Email search and profile enrichment |
| [Smart Email Finder and Verifier](../apis/smart-email-finder-verifier.md) | Name/domain email discovery |
| [Google Maps Email Extractor](../apis/google-maps-email-extractor.md) | Local listing contact enrichment |
| [Crunchbase Email Scraper](../apis/crunchbase-email-scraper.md) | Startup/company email discovery |
