# Phone Number Enrichment

APIs that can provide or extract phone numbers as part of lead records.

| API | Best Use |
| --- | --- |
| [B2B Leads Finder](../apis/b2b-leads-finder.md) | B2B leads with phone numbers |
| [Google Maps Email Extractor](../apis/google-maps-email-extractor.md) | Local business phones and emails |
| [LeadLocator Pro](../apis/leadlocator-pro.md) | Local phone and email collection |
| [AI Contact Details Scraper](../apis/ai-contact-details-scraper.md) | Website phone extraction |
| [Advanced Yellowpages Scraper](../apis/advanced-yellowpages-scraper.md) | Directory phone data |
| [192.com Businesses Scraper](../apis/192-com-businesses-scraper.md) | UK business directory contacts |
